# LP-EB-202610-BurgerPoint - [Sebastian Caleb Garrido tarrillo]

## Descripción del Proyecto
Landing Page responsive orientada a la centralización de canales de atención, presentación de menú artesanal, promociones grupales, ubicación y cotización para eventos corporativos de la marca **Burger Point**.

## Tecnologías Utilizadas
* HTML5 Semántico y accesible.
* CSS3 Puro estructurado con Flexbox y CSS Grid.
* JavaScript nativo para la validación de formularios de contacto y alertas dinámicas en el frontend.

## Justificación del Diseño
* **Paleta de Colores:** Se eligió una combinación de naranja brillante (`#FF9F1C`) para despertar el apetito del usuario y colores oscuros (`#1E1B18`) para garantizar un excelente contraste de lectura (diseño inclusivo y accesible).
* **Tipografía:** Se usa la tipografía *Bebas Neue* de Google Fonts para dar personalidad, contundencia y jerarquía visual a los títulos, y *Poppins* para el cuerpo de texto por su alto grado de legibilidad en pantallas tanto móviles como de escritorio.
* **Maquetación:** Diseñado con enfoque Mobile-First adaptativo, evitando que los elementos pierdan relación estética o balance en dispositivos pequeños.
